# MOON ARCADE 🌙

¡Bienvenido a **MOON ARCADE**! Un videojuego web estilo arcade de 8-bits y estética Lo-Fi desarrollado con el motor **Phaser 3**. El objetivo es simple: corre, salta y atrapa todos los objetos que caen del cielo para acumular puntos, avanzar de nivel y romper el récord global antes de que se agote el tiempo.

## ⚡ Características Principales

*   **Mecánica Catch-Up Arcade:** Lluvia procedural de objetos con velocidades progresivas e hitboxes calibradas (Pixel-Perfect).
*   **Diseño Adaptativo:** Soporte híbrido para jugarse en PC (Teclado) y Tablets/Móviles (Controles táctiles virtuales en pantalla).
*   **Banda Sonora de 8-Bits:** Música de fondo infinita (`mammamia8bits.mp3`) con interruptor de silencio localizado en español.
*   **Leaderboard del Sistema:** Historial local con el Top 7 de las mejores puntuaciones de la comunidad.

## 🛠️ Tecnologías Utilizadas

*   **Motor Gráfico:** Phaser 3 (v3.60+)
*   **Lenguaje:** JavaScript (Vanilla ES6)
*   **Estilos:** CSS3 para la interfaz de modales retro
*   **Persistencia:** LocalStorage (Fase MVP)

## 🚀 Instalación y Uso Local

1. Clona este repositorio en tu máquina local:
```bash
   git clone [https://github.com/RocketDev-TV/Proyecto-Moon.git](https://github.com/RocketDev-TV/Proyecto-Moon.git)
```

Abre el proyecto en tu editor de código favorito (ej. VS Code).
Levanta un servidor local (puedes usar la extensión Live Server de VS Code).
Abre src/html/index.html en tu navegador y ¡listo para jugar!
